# VeilProcure explainer — editable production source

Everything needed to re-edit or re-render the single film `../VeilProcure_Complete_Product_Explainer_178s.mp4`.

| Path | What it is |
|---|---|
| `remotion/` | The edit (Remotion 4.0.539, React 19). `src/timeline.json` is the cut; `src/*.tsx` draw the footage window, camera moves, highlights, captions, testnet badge, hook, diagram, RPC cards and outro. `public/footage/*.mp4` are the three screen recordings (constant 30 fps); `public/fonts` Manrope + JetBrains Mono (SIL OFL); `public/brand` the green logo and a video-only light version for dark backgrounds. |
| `audio/` | `narration/*.wav` (one file per line), `music_bed.wav` (original score), `final_mix.wav` (−16 LUFS, the film's soundtrack). |
| `scripts/` | `build_footage.py` (frames → footage + marker map), `build_timeline.py` (the edit decision list → timeline.json, SRT, audio cues), `mix_audio.py`, `write_docs.py` (script + EDL documents), `contact_sheet.py` / `stills.py` (shot picking), `reverse_logo.py`, `verify-rpc.mjs` (checks every transaction against NEAR testnet RPC), `narration/` (Kokoro TTS script and text), `music/` (score generator). |
| `evidence/` | Film run manifest (transactions, AI job, supplier balance), RPC verification results, the two aborted attempts. |
| `sheets/` | Contact sheets and gridded stills used to choose shots and place highlights. |
| `FEATURE_EVIDENCE_MATRIX.md` | Pre-production audit: what works, what is shown, where the proof is. |

**Not in the repository** (large; regenerated by the steps below): the three screen recordings `remotion/public/footage/*.mp4` (≈107 MB, from the raw frames in `.local/video/footage`), `audio/music_bed.wav`, `audio/premix.wav`, `audio/final_mix.wav`, render outputs and review sheets. The narration lines (`audio/narration/*.wav`) are included.

## Rebuild

```bash
# 1. footage (needs the raw frames in .local/video/footage from tests/e2e/specs/film.spec.ts)
python scripts/build_footage.py
# 2. narration (Kokoro, local) and score
python scripts/narration/tts.py      # paths expect .local/video/narration and .local/kokoro
python scripts/music/music.py
# 3. the cut, captions, documents, soundtrack
python scripts/build_timeline.py && python scripts/write_docs.py && python scripts/mix_audio.py
# 4. picture, then mux
cd remotion && npm install && npx remotion render src/index.ts Explainer out/explainer-video.mp4 --codec h264 --crf 16 --muted
ffmpeg -i out/explainer-video.mp4 -i ../audio/final_mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart ../../VeilProcure_Complete_Product_Explainer_178s.mp4
```

`npx remotion studio src/index.ts` opens the edit for frame-by-frame review.
