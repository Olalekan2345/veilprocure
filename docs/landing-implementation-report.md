## Copy that deliberately differs from the prompt

Claims were checked against the implementation; three prompt suggestions would have been inaccurate:

- "Only approved bids are revealed" → **"Every offer counts. None is opened early."** All committed quotes open to the buyer after the deadline; nothing is "approved" first.
- "Built with NEAR testnet • Private AI assisted evaluations" → **"Built on NEAR testnet · Private AI notes verified by attestation"** (the live attested path was verified on 2026-10-30, see `docs/AI_VERIFICATION.md`).
- The bid-privacy and FAQ copy states the trust boundary plainly: quotes are not cryptographically blind (the server holds the key), bidding is not anonymous, payments are testnet-only, the contract is unaudited.

No metrics, customer logos, testimonials, prices, transaction hashes or live records appear; every illustration is labelled ("Workflow illustration", "Illustration · not live data").

## Motion

CSS transitions/keyframes plus one IntersectionObserver script (`SiteMotion`); no animation library. A tiny inline boot script adds `vp-motion` before the body paints, so below-the-fold content can start hidden without a flash; without JavaScript nothing is ever hidden. Hero choreography finishes in ≈1.2 s (frames in `docs/ui-review/motion-sequence.jpg`); the headline is painted at first paint (starts at 25 % opacity, never transparent). Large statements reveal grey → ink rather than from invisible. `prefers-reduced-motion: reduce` disables reveals, parallax, floating and connector motion; the four-step rail shows complete. Only `transform`, `opacity`, `clip`/`color` are animated; no scroll hijacking or pinning.

## Known gaps

- Lighthouse **performance** score still to be measured on the hosted site (local trace failure above).
- The blocking time on throttled mobile comes from React/Next.js hydration; reducing it further would need fewer client islands or a lighter framework runtime.
- `/security`, `/privacy`, `/terms` and `/support` use the new header/footer, but their bodies keep the earlier serif/gold styling.
- No real product screenshots are used; the workspace preview is an abstract illustration (sanitised real screens would need the owner's consent).
- Screen recordings were inspected as frame captures (`motion-sequence.jpg`), not committed as video.
- A mint/dark variant of the logo was not created; the navy artwork is used only on light surfaces.
